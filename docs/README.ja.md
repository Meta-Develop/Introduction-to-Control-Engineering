# 制御工学入門

<p align="right">
  <a href="../README.md">English</a> | <strong>日本語</strong>
</p>

ここでは、制御工学を基礎から学ぶための公開教材を整備しています。本文は、高校数学で扱う関数や微分から出発し、変化する量をモデルとして表すところから、フィードバック系の解析と設計へ進みます。

扱う範囲は、微分方程式、伝達関数、周波数応答、状態空間表現、状態推定、最適制御、モデル予測制御、力学に基づくモデリングです。必要な概念は本文の流れの中で導入し、前提知識だけが独立して並ぶ構成にはしない方針です。

## ディレクトリ構成

| Path | 用途 |
|------|------|
| `ja/` | 日本語版の本文 |
| `en/` | 英語版のプレースホルダー |
| `common/style/` | 版をまたいで使う LaTeX スタイル |
| `docs/` | 節の流れ、設計方針、対応表 |
| `pdf/` | ビルドせずに読める PDF |

## ビルド

PDF はここから読めます。

- [日本語 PDF](../pdf/control-engineering-ja.pdf)
- [英語 PDF](../pdf/control-engineering-en.pdf)

手元で再生成する場合は次を実行します。

```sh
make ja
```

英語版は日本語版の構成が安定してから、同じ節構造を保って展開します。
