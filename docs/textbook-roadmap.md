# Textbook Roadmap

このファイルは、`制御工学入門` が最終的に到達すべき内容と進捗を管理するための公開ロードマップである。README ではなく、本文を増やす作業のためのチェックリストとして使う。

完成形は、短い概説ではなく、読むだけで制御工学の入口から大学院水準の話題まで進める単冊の教材である。すべてを入れるなら 1000 ページ級になっても不自然ではない。分量を抑えることより、定義、仮定、定理名、式変形、近似の理由、設計例を落とさないことを優先する。

応用事例そのものを本文の主役にしない。本文は一般理論を積み上げる教科書であり、読後に複雑な応用例を自然に理解できる状態を目指す。例は、熱系、RC 回路、質量ばねダンパ、DC モータ、振子のような低文脈の標準例を中心にする。

## Completion Levels

本文の各話題は、次の段階を通って完了に近づける。

1. 入口: なぜその概念が必要かを、制御対象の例から導入する。
2. 定義: 記号、単位、仮定、対象範囲を明記する。
3. 導出: 主要式を途中式つきで導く。
4. 読み替え: 時間領域、周波数領域、状態空間など別表現との対応を示す。
5. 設計例: 数値または物理モデルで、仕様から制御器まで計算する。
6. 実装注意: 飽和、遅れ、ノイズ、離散化、センサ、アクチュエータの制約を書く。
7. 検証: PDF を再生成し、公開ファイルに内部情報が入っていないことを確認する。

## Target Checklist

### 0. 数学と言葉の入口

- [ ] 数、量、単位、次元解析を制御例で説明する。
- [ ] 変数、関数、グラフ、比例、反比例、一次関数、二次関数を説明する。
- [ ] 三角関数、指数関数、対数関数を制御の振動・減衰・dB と結びつける。
- [ ] 複素数、複素平面、オイラーの公式を極・周波数応答の前に導入する。
- [ ] 微分を平均変化率から導き、速度、加速度、角速度へ接続する。
- [ ] 積分を面積と累積量から導き、状態更新と保存則へ接続する。
- [ ] 偏微分、勾配、ヤコビアン、ヘッセ行列を線形化と最適化の前に導入する。
- [ ] ベクトル、内積、外積、ノルム、射影を力学と状態空間に接続する。
- [ ] 行列、行列積、逆行列、ランク、行列式を状態空間に接続する。
- [ ] 固有値、固有ベクトル、対角化、正定値を安定性と LQR に接続する。
- [ ] 確率、期待値、分散、共分散、正規分布をカルマンフィルタの前に導入する。

### 1. 時間変化とモデル化

- [ ] 信号、入力、出力、外乱、ノイズ、状態を例で区別する。
- [ ] 平衡点、偏差変数、線形化、テイラー展開を制御対象で導く。
- [ ] 常微分方程式の解き方を一次系、二次系、連立一次系へ広げる。
- [ ] 物理法則から状態方程式を作る手順を、熱、電気、機械で示す。
- [ ] DC モータ、RC 回路、質量ばねダンパ、倒立振子のモデルを詳しく導く。
- [ ] 入出力モデルと状態空間モデルの対応を導く。

### 2. 古典制御の基礎講義

- [ ] ラプラス変換の定義、線形性、微分公式、積分公式、初期値・最終値の定理を導く。
- [ ] 逆ラプラス変換、部分分数分解、重根、複素共役極を例題で扱う。
- [ ] 伝達関数、極、零点、プロパー性、相対次数を導入する。
- [ ] 一次遅れ、二次遅れ、標準形、時定数、減衰比、固有角周波数を導く。
- [ ] 二次系の不足減衰、臨界減衰、過減衰をすべて解く。
- [ ] オーバーシュート、ピーク時刻、立上り時間、整定時間の式を導く。
- [ ] ブロック線図、等価変換、閉ループ伝達関数を全経路で整理する。
- [ ] 定常偏差、系の型、位置・速度・加速度誤差定数を例題で扱う。
- [ ] Routh-Hurwitz 判別法を一般表、特殊ケース、ゲイン範囲まで扱う。
- [ ] PID、PI、PD、二自由度 PID、微分フィルタ、アンチワインドアップを実装式まで扱う。

### 3. 周波数領域と古典設計

- [ ] 正弦波定常応答から周波数応答を導く。
- [ ] Bode 線図を因子ごとに手描きし、折点、傾き、位相を導く。
- [ ] ゲイン余裕、位相余裕、交差周波数、帯域幅、共振ピークを設計仕様に接続する。
- [ ] Nyquist の安定判別を偏角原理から説明し、不安定開ループ極を含む例を扱う。
- [ ] 根軌跡の作図規則、分岐点、漸近線、虚軸交差、出発角を例題で扱う。
- [ ] 位相進み、位相遅れ、遅れ進み補償を、仕様から設計する。
- [ ] フィードフォワード、カスケード制御、外乱オブザーバの入口を扱う。
- [ ] 感度関数、相補感度関数、ロバスト性、モデル誤差、むだ時間余裕を扱う。

### 4. 線形状態空間制御

- [ ] 状態方程式、出力方程式、行列指数関数、遷移行列を導く。
- [ ] 連続時間と離散時間の変換、ゼロ次ホールド、数値積分を扱う。
- [ ] 可制御性、可観測性、Kalman のランク条件を導く。
- [ ] 正準形、極配置、Ackermann の公式を扱う。
- [ ] オブザーバ、Luenberger オブザーバ、分離定理を導く。
- [ ] 内部安定性、BIBO 安定性、Lyapunov 安定性を区別する。
- [ ] Lyapunov 方程式と二次形式による安定判定を扱う。

### 5. 最適制御と確率的推定

- [ ] 変分、最適性条件、Hamiltonian、動的計画法の入口を説明する。
- [ ] 有限ホライズン LQR と連続時間 LQR を導く。
- [ ] Riccati 方程式を平方完成と HJB の両方から導く。
- [ ] LQG、分離原理、制御と推定の接続を扱う。
- [ ] 離散時間 Kalman フィルタの予測・更新を導く。
- [ ] 連続時間 Kalman-Bucy フィルタを扱う。
- [ ] 平滑化、情報フィルタ、チューニング、ノイズ共分散の意味を扱う。

### 6. 非線形制御と非線形推定

- [ ] 非線形状態方程式、局所線形化、接平面、ヤコビアンを再整理する。
- [ ] 非線形安定性、Lyapunov 直接法、LaSalle の不変原理を扱う。
- [ ] 入出力線形化、厳密線形化、零ダイナミクスを扱う。
- [ ] 受動性、エネルギー整形、バックステッピングの入口を扱う。
- [ ] スライディングモード制御、適応制御、ゲインスケジューリングを扱う。
- [ ] EKF を Kalman フィルタの非線形拡張として導く。
- [ ] UKF、粒子フィルタの入口を扱う。
- [ ] ESKF を姿勢、IMU、誤差状態の文脈で導く。

### 7. 力学モデリング

- [ ] 座標系、座標変換、回転行列、SO(3) を導く。
- [ ] Euler 角、ジンバルロック、四元数、指数写像、対数写像を扱う。
- [ ] Newton-Euler 方程式を質点、剛体、6 自由度へ広げる。
- [ ] 慣性テンソル、角運動量、剛体の運動エネルギーを導く。
- [ ] 仮想仕事、一般化座標、Euler-Lagrange 方程式を導く。
- [ ] 拘束、ラグランジュ未定乗数、接触、摩擦を扱う。
- [ ] 質点、振子、剛体、2 リンク機構のような標準例でモデル化を扱う。

### 8. MPC、NMPC、数値最適化

- [ ] 凸集合、凸関数、KKT 条件、双対性を導く。
- [ ] QP、線形制約、等式制約、不等式制約の解法を扱う。
- [ ] 離散時間予測モデル、予測ホライズン、制御ホライズンを導入する。
- [ ] 線形 MPC を QP へ落とし込む過程を行列で導く。
- [ ] 終端コスト、終端制約、再帰的実行可能性、安定性を扱う。
- [ ] NMPC、多重 shooting、直接 collocation、SQP、RTI を扱う。
- [ ] Gauss-Newton 近似、自動微分、ソルバ実装の入口を扱う。
- [ ] 制御配分、擬似逆行列、制約付き配分、冗長アクチュエータを扱う。
