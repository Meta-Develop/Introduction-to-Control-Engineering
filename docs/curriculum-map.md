# Curriculum Map

この教材は、必要な概念を使う直前に導入し、読者が前の大きな区切りへ戻らずに進める構成にする。参照用の整理は最後に置いてもよいが、本文の理解に必要な知識を付録へ逃がさない。網羅性を優先し、本文が辞典のような厚さになっても、疑問を未解決のまま先へ進ませない。

## Design Principles

- 高校数学から始め、微積分・線形代数・微分方程式は制御で必要になる順に導入する。
- 想定読者には、ベクトル・行列・微分積分をまだ学んでいない高校生を含める。ただし到達点は、大学院生が現代制御、推定、最適化、非線形制御を復習・参照できる範囲まで広げる。
- 網羅性を優先し、本文が長くなっても、定義、記号、単位、仮定、定理名、式変形、近似の理由を省略しない。
- 付録や参照表は整理用に限る。本文を理解するための前提知識は、使う直前に本文の流れの中で説明する。
- 古典制御と現代制御を別々の島にせず、同じ「動くものをモデル化し、望む動きへ近づける」流れでつなぐ。
- ニュートン・オイラー法とオイラー・ラグランジュ法は、単なる公式ではなく、モデル化の選択肢として比較する。
- 周波数応答、根軌跡、状態空間、LQR、カルマンフィルタ、MPC、NMPC を段階的に接続する。
- 特定研究の内容は本文の題材にしない。本文は一般理論を積み上げ、読後に複雑な応用例を自然に理解できる状態を目指す。
- 日本語版は `制御工学入門` の一枚表紙から始め、本文は一段組で読む。授業をそのまま書物へ戻すつもりで、式の省略や経験則だけの説明を避ける。
- 本文の主軸は「時間変化する対象をモデル化し、測れる量から状態を推定し、制約の中で望む動きを作る」ことに置く。各話題はこの主軸に戻る位置で導入し、独立した話題の列にしない。
- まず線形時不変系で応答、安定性、状態空間、状態フィードバック、オブザーバ、LQR、カルマンフィルタを一通りつなげ、その後に非線形系を線形化、座標・姿勢、EKF、ESKF、NMPC への拡張として扱う。
- 推定はカルマンフィルタを基準に置き、EKF はその非線形拡張、ESKF は姿勢や誤差状態を扱うための EKF の発展として順に導入する。
- MPC は、離散時間モデル、有限ホライズン最適制御、制約付き最適化、サンプリング、入力飽和、アクチュエータ制約を学んだ後半で導入する。
- 数学は高校で読める入口から始め、必要になった場所で小さく導入してすぐ制御の式へ戻す。微積分、線形代数、確率、最適化を独立した準備章として切り離さない。
- 定義、定理、公式、有名な判別法を使うときは必ず名前を明記し、「何を仮定したから何が言えるか」を本文に書く。
- 式変形は途中を飛ばさない。高校数学から読み始める読者が、感覚的な説明と記号の操作を同じ場所で結びつけられる密度にする。

## Source Coverage Targets

既存教材で扱われていた次の内容は、一般化して本文へ取り込む。

- 微積分、線形代数、常微分方程式、行列指数関数、離散化
- 座標系、回転行列、オイラー角、ジンバルロック、四元数
- 剛体運動、慣性テンソル、ニュートン・オイラー方程式、6自由度モデル
- フィードバック、PID、カスケード制御、フィードフォワード
- 状態空間、線形化、可制御性、可観測性、安定性、リアプノフ法
- 状態フィードバック、極配置、オブザーバ、分離定理
- LQR、有限ホライズン最適制御、MPC、NMPC、SQP、RTI
- カルマンフィルタ、EKF、ESKF、IMU センサモデル
- 制御配分、冗長アクチュエータ、擬似逆行列、制約付き最適化

不足しているため新たに補う内容は次の通り。

- ラプラス変換、伝達関数の導出、極と零点
- 1次遅れ、2次遅れ、標準形、過渡応答仕様
- ボード線図、ナイキスト安定判別、根軌跡
- オイラー・ラグランジュ方程式、一般化座標、拘束
- ロバスト性、外乱、モデル誤差、感度関数
- 実装上の量子化、ノイズ、サンプリング周期、計算遅れ
